1.2 为什么一定要初始化

上电或复位后，GPIO 可能处于输入、高阻、复用或芯片规定的默认状态，不能假设它已经符合应用需求。没有初始化就直接使用，可能导致：

  • 输出引脚仍是高阻，驱动器没有得到有效控制；
  • 输入引脚悬空，读取结果随机跳变；
  • 上拉或下拉方向错误，按键和故障信号逻辑相反；
  • PWM、定时器或串口没有切换到正确的复用功能；
  • 电机使能、方向和刹车信号在启动瞬间处于危险组合；
  • 不同复位原因或不同编译配置下出现不一致现象。

电控系统尤其需要先初始化为安全状态。例如电机控制引脚应先关闭使能或输出零占空比，再配置方向和 PWM 功能，最后才允许驱动器工作。这样可以避免单片机启动过程中短暂的随机电平让电机突然转动。

1.3 H 桥的工作原理

H 桥可以抽象为四个开关和一个电机。电机位于桥臂中间，四个开关分别控制电机两端接到电源正极或地：

四个开关不能任意组合。典型状态如下：

Q1 Q2 Q3 Q4 电机状态
1 0 0 1 正转
0 1 1 0 反转
0 0 0 0 滑行或断电停止
1 1 0 0 左侧桥臂直通，禁止
0 0 1 1 右侧桥臂直通，禁止

正转时，电流从电源经过 Q1、电机和 Q4 流向地；反转时，电流经过 Q3、电机和 Q2 流向地。改变电流方向，就改变了电机的转矩方向。

上下桥臂同时导通会形成电源到地的低阻通路，称为直通。直通会产生很大的瞬时电流，可能损坏驱动器或电源，因此驱动器通常会加入死区时间、互锁和过流保护。软件也不能在切换方向时让两路输出短暂地同时有效，安全做法是先关闭原方向输出，再设置另一方向，并在必要时插入短暂的空档时间。

PWM 通常用于控制桥臂的平均电压。电机绕组具有电感，电流不会瞬间变为零，因此关闭开关后仍可能通过驱动器的续流二极管或 MOSFET 体二极管流动。不同的续流方式会影响制动、噪声、发热和电流纹波，具体应以驱动器拓扑和手册为准。

“方向+PWM”接口通常由一个方向信号选择电流方向、一个 PWM 信号调节平均功率；“A/B 双输入”接口则通常分别控制桥的两路输入。两者的真值表和停止方式可能不同，不能把一种接口的控制逻辑直接套到另一种接口上。

2. PWM 的三个关键概念

2.1 频率

PWM 频率决定一个周期的快慢。频率过低可能产生可听噪声和明显转矩波动；频率过高则会增加开关损耗或超出驱动器适用范围。应优先采用驱动器和电机允许的频率，而不是盲目追求更高频率。

2.2 占空比

占空比定义一个周期内高电平所占的比例：

$$
D=\frac{t_{\mathrm{on}}}{T}\times 100%.
$$

在理想情况下，占空比越大，电机平均端电压越高，转速越高。但实际电机有启动转矩、负载、摩擦和电池电压等因素，低占空比可能无法带动轮子。

2.3 有效电平和极性

驱动器可能是高电平有效，也可能是低电平有效。即使 PWM 数值相同，如果有效电平理解错误，也会出现：

  • 上电自动转；
  • 目标为零仍有输出；
  • 正反方向相反；
  • 两个轮子的动作不一致。

3. 从开环测试开始

开环控制不读取编码器，只根据设定值输出 PWM：

$$
u=u_{\mathrm{target}}.
$$

开环的目的不是获得精确速度，而是确认硬件链路：

推荐测试顺序：

  1. 上电，确认两轮停止；
  2. 只测试左轮；
  3. 只测试右轮；
  4. 两轮同时正转；
  5. 两轮同时反转；
  6. 停止并等待，确认不会自动重新启动。

如果开环就不正常，不能通过调 PID 解决。应先检查电源、GND、PWM 通道、A/B 映射、有效电平和电机线。

4. 编码器和速度测量

编码器把电机轴或轮子的转动转换为脉冲。增量编码器通常有 A、B 两路：

  • A 路提供脉冲；
  • B 路用于判断方向；
  • 两路相位关系可以区分正转和反转。

在固定采样周期内，最简单的速度反馈是读取增量计数：

$$
v[k]=\frac{\Delta C[k]}{T_s}.
$$

如果暂时不换算单位，可以直接使用“一个采样周期内的脉冲数”。这种方式适合第一阶段调试，因为不需要立刻知道编码器线数、减速比和轮径。

必须验证正转时反馈符号是否符合控制约定。如果电机正转而编码器反馈为负，PID 会把误差越调越大，表现为持续加速或输出饱和。

5. 为什么要使用固定控制周期

PID 的计算依赖采样时间。如果有时 5 ms 更新一次、有时 30 ms 更新一次，同一组参数会产生不同控制效果。

6. 为什么以及何时在中断中运行 PID

PID 是否放在中断中，不是由“中断一定更快”决定的，而是由控制周期、实时性要求和任务执行时间共同决定的。将 PID 放在定时器中断中，主要有三个原因：

  1. 周期稳定：中断由硬件定时器触发，不容易受到主循环中其他代码执行时间的影响；
  2. 采样和计算同步：可以在固定时刻读取编码器，再立即完成控制计算；
  3. 输出及时：计算结果能够按固定周期更新 PWM，减少控制延迟和周期抖动。

例如，速度环需要每隔固定时间读取一次编码器增量并更新 PWM，就可以由定时器中断产生“速度环更新事件”。但这不意味着所有 PID 代码都必须直接写在中断服务函数中。更稳妥的做法是让中断只完成短小、确定的实时工作：

如果控制计算很短、周期要求严格，并且已经确认中断执行时间小于周期，也可以直接在定时器中断中调用速度 PID。相反，图像处理、串口打印、复杂滤波、动态内存操作和阻塞等待不应放进高频中断，否则会延迟其他中断，造成丢数据、系统抖动甚至看门狗复位。

把 PID 放入中断前应确认：

如果控制要求不高，或者 PID 计算较复杂，也可以让中断只设置标志位，由主循环或周期任务执行。关键不是追求“全部放中断”，而是保证采样周期、计算延迟和数据同步满足闭环控制要求。

7. PID 的基本原理

7.1 为什么需要 PID

只使用固定 PWM 属于开环控制。相同的 PWM 占空比在不同电池电压、负载、地面摩擦和电机个体差异下，得到的实际速度并不相同。开环适合验证电机能否转动，但很难保证速度准确，更不能主动补偿上坡、载荷变化或左右轮差异。

PID 的价值不是让电机“自动变快”，而是让系统在扰动存在时仍尽量跟踪目标。它可以改善启动响应、减小稳态误差，并在负载变化后自动补偿。PID 也不是万能的：反馈方向错误、采样周期不稳定、输出饱和或传感器失效时，PID 可能放大问题，所以闭环前必须先验证硬件和反馈链路。

7.2 电机 PID 和舵机 PID 的区别

这里的“电机”通常指带编码器的直流电机或减速电机，“舵机”通常指内部已经集成控制电路的位置执行器。两者都可以使用 PID，但控制对象、反馈量和输出形式不同：

对象 常见控制目标 反馈 控制器输出
直流电机速度环 转速或轮速 编码器脉冲、测速值 驱动器 PWM 和方向
直流电机位置环 轴的位置 编码器位置 内层速度或电流控制目标
舵机位置环 舵盘角度 内部电位器或磁编码器 脉宽、总线位置命令或内部目标值

电机速度 PID 的输出通常直接影响电压或电流，更新周期可以较短，输出还要处理启动死区、方向切换、限幅和积分饱和。舵机接收的往往是角度或脉宽命令，位置闭环可能已经在舵机内部完成；外部再做一个位置 PID 时，必须考虑内部控制环的响应速度，否则两个控制器可能互相“抢控制权”，产生振荡。

因此，不能因为都叫 PID，就直接复用同一组参数。电机控制更关注速度、转矩和负载扰动；舵机控制更关注位置误差、响应时间、机械限位和目标角度平滑。使用智能舵机时，首先应确认它是否已经自带位置控制，再决定外部是否需要增加控制环。

控制目标是让实际速度接近目标速度。定义误差：

$$
e[k]=r[k]-v[k].
$$

离散 PID 可以写成：

$$
u[k]=K_p e[k]+K_i\sum_{i=0}^{k}e[i]+K_d(e[k]-e[k-1]).
$$

比例项

比例项根据当前误差立即产生输出：

$$
u_P=K_p e.
$$

误差越大，输出越大。比例过小，电机跟不上目标；比例过大，可能产生抖动或超调。

积分项

积分项累计长期误差：

$$
u_I=K_i\sum e.
$$

它可以消除负载造成的稳态误差，但如果输出已经饱和仍继续积分，就会产生积分饱和。因此需要积分限幅，并在目标速度为零时清除积分。

微分项

微分项关注误差变化速度：

$$
u_D=K_d(e[k]-e[k-1]).
$$

它可能帮助抑制变化过快，但编码器增量反馈通常有量化噪声，微分项过大容易放大噪声。第一版速度环可以先使用 PI，再根据实际响应决定是否加入 D 项。

PID 参数需要根据电机、负载、电池、编码器和采样周期重新整定。不要把其他项目的参数直接当成最终参数。

10. PID 调参顺序

推荐按照以下顺序：

第一步：确认反馈方向

让轮子以较低开环输出转动，确认编码器反馈方向和电机正方向一致。

第二步：只调比例

先设定：

逐渐增大 Kp，观察电机能否跟随目标速度。出现明显振荡时，说明比例已经偏大。

第三步：加入少量积分

在比例控制基本稳定后，逐渐增加 Ki，用来消除负载下的稳态误差。必须配合积分限幅和目标为零时清积分。

第四步：谨慎考虑微分

如果速度反馈噪声明显，不要急着加大 Kd。可以先对速度测量做合理滤波，再评估微分项是否有必要。

11. 正常与异常现象

正常

  • 上电后电机保持停止；
  • 低档目标启动平稳；
  • 左右轮方向一致；
  • 提高目标速度后，实际转速随之提高；
  • 稳态时不会持续加速；
  • 发出停止命令后不会自动重新启动。

异常

现象 优先检查
上电自动转 PWM 初始值、驱动器有效电平、使能脚
左右轮对应反了 A/B 通道和逻辑左右映射
两轮都反转 A/B 极性或方向符号
持续加速 编码器反馈方向、目标符号、Ki/Kp
明显抖动 Kp/Ki 过大、采样周期不稳定、反馈噪声
低档不动 启动转矩不足、负载过大、电池电压不足
停止后又启动 目标没有清零，或旧命令被重新发布
